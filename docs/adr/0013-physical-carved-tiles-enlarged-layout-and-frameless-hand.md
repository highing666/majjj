# 国标机麻厚玉雕版实体牌面、横屏跨栏放大布局与无压暗无框手牌契约

为了修正 `#78` 双人实机试玩暴露出的三项牌桌核心观感与交互问题（牌面仍不够像实体中国麻将、大屏与横屏手机下牌面偏小、非`自家`回合手牌压暗加框打断看牌与理牌视线），经 `prototype/traditional-tiles-v2`（提交 `3f95456`）三套结构差异变体在 14" MacBook Pro、13" MacBook Air M2、iPhone 13 Pro 与 iPhone 17 上的实机对比签收，我们最终拍板 **变体 A「国标机麻·厚玉雕版」**，并决定：**继续坚守 `ADR-0001` 与 `ADR-0007` 的深青暖珀桌布基调、单张 `@2x` 图集（`≤ 2048×2048`）与 `maxDpr = 2` 契约，对 `ADR-0009` 作出三项受控修订——① 将 34 张`数牌`/`字牌`升级为去黑描边、立/倒真厚度、满版粗刻魏碑字形与靛蓝回纹框`白板`的 `1920×2048`（单帧 `184×248`）实体厚玉图集；② 放开底排`自家`手牌跨出中栏按实际`鸣牌`动态让位，解除 `62px / 34px / 28px` 低天花板并同步放大结算缩略牌；③ 彻底取消非`自家`回合压暗及手牌外框/逐张金框，改以清爽无遮挡的回合提示呈现**。

## Considered Options

- **延续 `ADR-0009` 原「玉骨工笔」平面黑描边牌体、系统细楷体、`1 条`/`1 筒`水彩插画与大陆纯白光板`白板`**：实机试玩下黑框扁平感强、笔画偏细且`白板`在缩小`牌河`中辨识度弱，未能达到实体中国麻将的厚重直觉。
- **选用原型变体 B「古法骨牌·暖象牙手刻」或变体 C「精雕棋牌·极速高辨识」**：变体 B 色调偏暖复古、高光块感略弱；变体 C 缩窄牌边厚度换取字号，实体亚克力厚玉质感不如变体 A 均衡；实机对比后变体 A 在放大后的 Mac 与 iPhone 上同时兼顾了实体厚重感与远距清晰度。
- **保留 `ADR-0009` 的非`自家`回合压暗手牌与整排/单张金框**：虽然强化了明暗反差，但在等待他人行动期间频繁看牌与盘算`听牌`路线时会持续打断视线，且多层金框切割了实体麻将牌的整体观感。
- **维持三栏中栏硬边界与 `62px / 34px / 28px` 宽度硬上限**：会导致 13"/14" MacBook 及更大屏幕无法吃满宽屏余量，iPhone 横屏手牌仅约 `32px` 宽、点按局促。

## Consequences

- **实体厚玉雕版牌面与 `1920×2048` 单图集（修订 `ADR-0009` 牌面、`白板`与单帧规格）**：
  - **图集提清**：在严格守住单张 `≤ 2048×2048` 契约的前提下，将 `tiles@2x.png` 网格升级为 `10×8`、`cellW = 192`、`cellH = 256`、`frameW = 184`、`frameH = 248`、`pad = 4`（总尺寸 `1920×2048` `@2x`），确保桌面端放大至 `88px` 逻辑宽仍保持 Retina 锐度。
  - **立/倒双牌体真实立体厚度**：取消生硬 `2.6px` 粗黑外描边，改用亮乳白亚克力渐变块面、细微边线与饱满翡翠绿厚背；`自家`立牌体在**顶部**呈现厚实翡翠绿牌背与圆润象牙高光倒角，`牌河`与`鸣牌`倒牌体在**底边**呈现象牙侧壁 + 翡翠绿厚底托 + 柔和落影，`body_laid_back` 同步呈现倒扣绿顶与底侧象牙托。
  - **满版粗刻字形与统一雕版条筒**：`万子`与`字牌`改用 `WeibeiTC-Bold`（回退 `STKaitiTC-Black`）叠加描边加粗与阴刻高光/凹槽阴影；`1 条`（幺鸡）与 `1 筒`（十二瓣大花轮）直接在确定性 CoreGraphics 光栅管线内以同一套红/绿/靛蓝/金浓漆与阴刻光影绘制，消除此前水彩贴图割裂；`2–9 条`（全绿/红绿、无蓝条、对称 M/W 八条）与 `2–9 筒`全面加粗加大。
  - **经典蓝框`白板`（修订 `ADR-0009`）**：放弃极淡纯白光板，改为高辨识度的**靛蓝双线回纹框`白板`**，同步更新浏览器兜底 Canvas 图集渲染器（`tileAtlas.ts`）与全站 `TileBadge`（动作栏 `xs` 维持 `22×30` 紧凑不挤按钮，结算与战绩 `sm` / `md` 放大至 `30×41` / `38×52`）。
  - **桌布保持不变**：继续保留既有深青暖珀厚涂桌布（`feltBackdrop.ts`），衬托高明度乳白厚玉牌体并与`牌友角色`头像和漫画气泡保持视觉统一。
- **横屏跨栏放大布局与动态让位（演进 `ADR-0009` 布局几何）**：
  - 允许底排`自家`手牌突破中栏限制，在紧凑化底左`自家`名牌与右翼边界之间延展（避让`快捷互动`栏），并按`自家`实际公开`鸣牌`组数在底右动态让位与居中，消除底部宽屏闲置与重叠风险。
  - 解除低天花板：将逻辑宽度上限放开至 `handTileW ≤ 88px`、`riverTileW ≤ 46px`（中路`牌河` 10 张/行，侧翼`牌河`按双列 6 张/列桌面、5 张/列矮横屏排布以收窄两侧翼宽）、`meldTileW ≤ 38px`，并在 14" MacBook Pro（`1512×982`）、13" MacBook Air M2（`1470×956`）、iPhone 13 Pro（`844×390`）与 iPhone 17（`874×402`）上确保与`牌友角色`头像区、`牌桌台词`气泡及中盘零重叠。
- **无压暗、无外框手牌回合态（修订 `ADR-0009` 四层出牌强提示）**：
  - 任何时刻都不压暗`自家`手牌（`dimViewerHand` 恒为 `false`，非`自家`回合与动效锁定期间均保持 `alpha = 1`、`tint = 0xffffff`）。
  - 彻底移除整排手牌托盘框（`turn-tray-idle` / `turn-tray-active` / `turn-tray-breath`）、`碰`后逐张立牌金框及刚摸入牌的双层金框。
  - 保留不打断视线的清爽提示：刚摸入牌保持独立间距 + 轻微上抬 + 顶部小巧金三角 `▼`；轮到`自家`回合通过桌布底部柔和暖光晕、手牌上方金色胶囊（「轮到你出牌」/「轮到你出牌 · 碰后请择牌打出」）、中盘方向边灯与`自家`名牌高亮提示；悬停与点选单张牌维持原有上浮与选中反馈。
- **原型留档与生产实现边界**：
  - 原型分支 `prototype/traditional-tiles-v2`（提交 `3f95456`）仅作一手视觉参考存档于 `main` 之外，绝不直接合入生产分支；正式落地须通过 `/to-spec` → `/to-tickets` 与 TDD 正规重写并更新对应单测断言。
