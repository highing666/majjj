# LLM 自主发言与沉默变脸、整场对局上下文、本地模型原生思考及牌友角色真人化（修订 `ADR-0010` 与 `ADR-0014`）

在实机游玩体验中，原 `ADR-0010` 与 `ADR-0014` 下的表现层暴露出明显的机械感：代码硬编码了每`小局`开局必发、每次`鸣牌`（含普通`碰`）必触发且附带固定接话链，加上 3.5 秒短冷却与完全无对话历史的单轮调用，导致 AI 发言密集却流于表面、频繁重复“甩锅发牌员”与句首硬带人名，缺乏真人麻将桌的牌运情绪起伏、有梗接茬与自然闲聊。我们决定在坚守纯局域网 `llama-server`（零公网、无认证）、纯 CPU 强 AI 决策（`ADR-0004`）与绝不偷看他家暗牌（`ADR-0010`）三条红线的前提下，**把“要不要开口”与“情绪演进”彻底交由开启原生思考模式并吃进整场`对局`上下文的本地 `Qwen3.5-9B` 自主判断，同步取消局中同步阻塞、改用 2–18 字自然短句并将 5 位`牌友角色`全面真人化**。

## Considered Options

- **仅在代码层调低触发概率与拉长冷却（如全桌 10–15 秒冷却 + 普通`碰`低概率采样）**：虽能减少刷屏密度，但本质仍是规则驱动的机械触发，无法理解当前牌桌气氛、刚聊到哪儿或自家牌运累积的情绪拐点，仍然“笨”且死板。
- **通过 JSON 首字段 `"thought"` 模拟思考，继续在模型侧关闭原生思考**：只是关闭思考模式下的提示词权宜之计，无法释放 `Qwen3.5-9B` 原生后训练推理能力；在放弃外部云端模型、专注纯局域网 `llama-server` 后，直接打开模型侧原生思考开关更正统且上限更高。
- **同时引入 `https://` 与 `Bearer` API Key 以支持外部云端强模型及 `json_object` 兼容降级**：会增加宿主机密钥存储、远程访客隔离与多后端解析兼容的显著设计复杂度；当前优先榨干局域网本地 `Qwen3.5-9B` 的上下文与原生思考能力，保持零公网依赖架构纯净。
- **保留原有 5 个标签化角色名（急眼快攻哥等）仅改写提示词**：角色名本身自带强烈机器标签味，无论牌桌展示还是模型互相称呼都极易出戏，直接改为熟人日常称呼体验提升最直接。

## Consequences

- **本地 `Qwen3.5-9B` 原生思考模式与扩宽单槽上下文（修订 `ADR-0010`）**：
  - `BENDER` 侧 `llama-server` 启动参数从 `--parallel 3 -c 12288 --reasoning-budget 0` 调整为更大单槽上下文与受控原生思考配置（如默认 `--parallel 2 -c 16384`，每槽 `8192` tokens；开启 `enable_thinking: true` 并配置可调 `--reasoning-budget`，默认甜点值约 `256` tokens，在实现前须经 `BENDER` 实机冒烟验证思考链分离与 `json_schema` 严约束合规率）。
  - `mahjong-server` 放行响应中的 `reasoning_content`（可记录调试日志用于提示词调优，不再误判为故障，仅保留对 `content` 泄漏 `<think>` 的防线），并将单次 LLM 请求超时由 `6s` 放宽至约 `20s`。
  - 结构化输出契约演进为 `{ "speak": bool, "mood": PersonaMood, "text": string }`（仍严格受 `json_schema` 约束）；保持纯局域网无认证架构不变。
- **由 LLM 自主决定“说不说”与沉默变脸（修订 `ADR-0010`）**：
  - 彻底移除代码侧“开局必说 / 每`碰`必说 / 固定概率抽样 / 死板冷却”规则，改为轻量唤醒边界：每个 AI 在自己每巡出牌后异步巡检 1 次；遇到人类`鸣牌`/开杠、`快捷互动`、慢思考空档或`小局`结算时异步唤醒 1 位最相关 AI；当某位 AI 真正开口（`speak: true`）后，延迟约 1 秒串行唤醒 1 位其余 AI 自主决定是否接茬，单段互动最多自然串行接 2 轮；同一座次同时最多 1 个在途推理防撞车。
  - **沉默亦可更新`牌友情绪`**：当模型返回 `speak: false` 时，服务端不弹出气泡也不触发`台词语音`，但若`牌友情绪`发生变化，仍通过轻量服务端消息（如 `PersonaMoodUpdated`）实时更新对应座次头像表情差分。
  - 在上下文中提供“距上次发言已过 X 巡”等客观线索，以提示词软引导克制感（普通无波澜回合默认 `speak: false`），不靠硬编码冷却掐断灵光一现的接梗。
- **全程非阻塞异步与分级过时阈值（修订 `ADR-0010` 与 `ADR-0014`）**：
  - 彻底取消 `1.5s` 高光短同步阻塞，局中与`小局`结算发言全部非阻塞异步送达，以“允许慢几秒换更聪明”为原则，绝不拖慢出牌手感。
  - 过时丢弃按场景分级：针对刚发生动作的强时效接话，在局面推进超过约 `8–10` 步后丢弃；针对自身牌运吐槽、日常闲聊与结算复盘，只要尚未切换至下一`小局`即允许自然弹出。
- **整场`对局` 6 块单座上下文与真人日常闲聊（修订 `ADR-0010`）**：
  - 严格维持单座视角与绝不偷看他家暗牌底线，向模型提供 6 块结构化现场上下文：① 本场`对局`战况编年史（实时分差、排名与过往各`小局`胜负番型/连庄/连败）；② 本`小局`公开动态与`牌河`画像（全部`鸣牌`、近期`摸切`/`手切`节奏与花色集中态势）；③ 自家手牌、`预计算手牌事实`、本`小局`起手好坏与牌运起伏轨迹及当前`牌友情绪`；④ 跨`小局`滚动保留约 15–20 句的`牌桌对话流`；⑤ 既有跨`对局``牌友记忆`；⑥ 当前现实星期与时段语境。
  - 允许穿插约 15%–25% 与当前`小局`无关的熟人日常闲聊与自然玩梗（如饭点、夜宵、加班摸鱼、手气玄学等），并允许同桌顺势接闲聊的茬。
- **短句自然口语、去套路化与 5 位`牌友角色`真人化（修订 `ADR-0014`）**：
  - 取消 `ADR-0014` 中 `10–26 字` 的强制下限假设，改为提示词引导 `2–18` 字自然口语短句（常态 `4–14` 字，服务端仅对极端失控如超 `40` 字兜底），显著缩短单句`台词语音`合成耗时；默认不带人名直接开口，彻底清除“甩锅发牌员”硬编码提示词诱导（并同步优化`快捷互动`中“发牌员演我”文案）。
  - 保留原有 5 个内部 `PersonaId` 枚举键、漫画厚涂头像图集、`角色语音包`映射及历史`牌友记忆`存储键零破坏，将展示昵称与人物小传全面真人化为熟人牌友：**大川**（`QuickHothead`）、**小晚**（`TeaSarcasm`）、**大鹏**（`StubbornBlamer`）、**小桃**（`ChaosInstigator`）、**老陈**（`TiltedMaster`）；TTS 侧 `personas.json` 保留旧名作为 `aliases` 确保平滑兼容。
