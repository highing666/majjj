# 双栈 IPv6 按需远程联机、三层网络隔离与入桌口令门禁

为了让家庭牌桌在不引入公网中继服务器、账号体系或客户端虚拟专网的前提下，支持通过家庭宽带公网 IPv6 邀请远程朋友用浏览器直连加入`对局`，同时守住局域网日常零摩擦体验、公共 Wi-Fi 防误暴露与家庭隐私数据安全，我们决定采用 **「默认 `[::]:8789` 双栈监听 + 应用层默认关闭/宿主按需一键开启`远程联机`」**、**「`Loopback / LAN / Remote` 三层 `peer + Host` 双校验网络信任边界」**、**「服务端内置极简门禁页 + 8 位动态`入桌口令`换取 `HttpOnly` 会话 Cookie」**，以及 **「保持纯 `http://` + `ws://` 零证书直连并预留自定义域名与未来本机 TLS 反代安全底座」**。本决策对 `ADR-0002`、`ADR-0005`、`ADR-0006` 作出受控演进，并严格坚守 `ADR-0001` 服务端零外部公网依赖红线。

## Considered Options

- **首版强制内置 TLS/HTTPS 或强绑本机 Caddy 反向代理**：家庭宽带普遍封禁 `80`/`443` 端口，虽可借 DNS-01 自动签发非标端口证书，但会引入独立守护进程、DNS API 密钥管理与证书运维门槛；先以纯 `http://` + `ws://` 搭配短生命周期动态`入桌口令`直连，并通过 `peer + Host` 双校验为二期外挂本机 TLS 反代留好安全底座，迭代风险最低。
- **不直接开放公网 IPv6，改走 Tailscale / Surge Ponte 等虚拟专网**：要求远程朋友额外安装并配置对应客户端或加入同一私网，违背「发链接给朋友、浏览器点开即打牌」的零安装目标。
- **服务端启动即常开公网接入，或要求家庭局域网设备也输入口令**：前者违背 `ADR-0006` 对携带 Mac 接入咖啡馆/公司公共 Wi-Fi 暴露牌桌的防护原则；后者破坏 `ADR-0005` 家庭内网扫码/桌面图标零摩擦直连体验。
- **将与宿主机同 `/64` 前缀的公网 IPv6 视为局域网免密放行**：在咖啡馆、酒店或校园网等共享 Wi-Fi 下，陌生设备常与宿主机处于同一 IPv6 `/64` 网段；将全部公网单播 IPv6（`2000::/3`）一律按 `Remote` 处理边界清晰，且允许宿主在家里用手机点公网链接真实演练口令门禁。
- **公网未认证时仍放行前端 SPA 静态资源，仅在前端渲染口令输入页并拦截 `/ws` 与 `/api/*`**：会把前端包、版本号与语音资源暴露给全网扫描器，且在认证前产生多余静态传输与界面闪屏；改由服务端对未认证 `GET /` 返回极简内联中文门禁页（其余路径一律 `403`）暴露面最小。
- **在 `mahjong-server` 内置 DDNS 客户端或访问第三方外网接口自检端口可达性**：会引入公网出站依赖、云厂商凭证存储与外部服务故障耦合，违背 `ADR-0001`；路由器放行、DDNS 与 Surge 联动检查归入独立运维文档与向导脚本更清晰。

## Consequences

- **双栈监听与按需开关（受控演进 `ADR-0005` / `ADR-0006`）**：
  - `mahjong-server` 默认通过 `socket2` 绑定 `[::]:8789` 并显式设置 `IPV6_V6ONLY = false`，在 macOS 与 Linux 单 socket 同时承接 IPv4（`127.0.0.1`、私有局域网）与 IPv6 连接，保持既有 `Majjj.app` 启动器与部署脚本全兼容；仅在未显式传 `--bind` 且宿主机内核禁用 IPv6 时告警回退至 `0.0.0.0:8789`。
  - `远程联机`默认关闭（关服/重启恢复关闭，除非显式传 `--allow-remote` / `MAJJJ_ALLOW_REMOTE`）；宿主仅在 `Loopback` 界面可见控制入口（同时覆盖大厅侧栏与局中顶部快捷入口），可随时开启/关闭、重置`入桌口令`并查看当前在线远程连接数。
- **三层网络隔离、`peer + Host` 双校验与 Web 安全加固（受控演进 `ADR-0002`）**：
  - **`Loopback`（仅本机宿主）**：要求 TCP `peer`（经 canonical 归一化，含 `::ffff:127.0.0.1`）与 HTTP `Host` 头**同时**为回环；独占 `POST /api/shutdown`、`远程联机`开关、`入桌口令`重置与自定义公网入口保存等宿主控制接口。
  - **`LAN`（家庭局域网）**：要求 `peer` 为回环、RFC1918 私有 IPv4、`fe80::/10` 或 `fc00::/7`，**且** `Host` 头为回环、私有 IPv4 或 `.local`；继续零口令直连，并独享 `/api/stats`、`/api/preferences`、`/api/history/{export,clear}`、`/api/persona-memory{,/clear}` 与未认证 `/api/health`。
  - **`Remote`（公网与非局域网域名入口）**：所有公网单播 IPv6（`2000::/3`，含同 `/64`）、公网 IPv4，以及携带公网域名 `Host` 头的请求（即便经由本机 `127.0.0.1` 反向代理转发）一律归为 `Remote`，从架构上杜绝未来套本机 TLS 反代时的权限逃逸。
  - **门禁、限流与防跨站**：`远程联机`关闭时对一切 `Remote` 请求返回极简 `403`；开启后未认证 `Remote` 仅 `GET /`（含 `/?code=...`）返回极简内联门禁页，通过 8 位去混淆高熵`入桌口令`向 `POST /api/remote-auth` 换取随机 `HttpOnly; SameSite=Lax; Path=/` 会话 Cookie（并清除地址栏 `?code=`），之后仅放行静态资源、`/ws` 与 `/api/banter-audio/{banter_id}`。口令校验按 IPv6 `/64`（IPv4 `/32`）+ 全局双层防爆破限流；服务端默认不信任 `X-Forwarded-For` / `Forwarded`；`GET /ws` 强制同源 `Origin` 校验（防 CSWSH）；变更类 `POST /api/*` 强制校验 `Content-Type: application/json`（防简单请求 CSRF）。
- **脱敏、撤销语义与牌桌行为边界**：
  - 发往 `Remote` 客户端的 `TableSnapshot` 清空 `lan_urls`（不泄露内网 IPv4 与 `.local` 主机名），前端同步隐藏局域网扫码栏、历史战绩/牌友记忆管理与关服入口。
  - 点击「重置口令」仅生成新口令并作废旧口令，保留已入桌远程牌友继续完成当前`对局`；点击「关闭`远程联机`」立刻作废全部远程会话 Cookie 并断开所有已连远程 WS。
  - 持有效会话的远程牌友正常计入历史战绩与`牌友记忆`，并允许在`对局`进行中接管空余 AI 座次（复用既有 `seat_generation` 防竞态）；但**严禁远程连接接管任何人类离线座次**（远程牌友断线仅凭自身 `seat_token` 自动重连），同时对远程`快捷互动`保持基础冷却以保护局域网 GPU 推理节点。
- **地址发现、可选自有域名与 Surge/运维边界（坚守 `ADR-0001`）**：
  - 公网 IPv6 发现排除 `utun`/`bridge`/`awdl`/`llw`/`lo`（兼容 Surge Enhanced Mode 等虚拟网卡）及链路本地/ULA/临时/废弃地址，优先选取稳定的公网单播 IPv6（macOS 优先非 `temporary` 地址）。
  - 支持在本地 `preferences.json`、宿主面板或 `--public-url` / `MAJJJ_PUBLIC_URL` 配置自定义公网域名（解决微信裸 IPv6 断链与前缀轮换导致的 `localStorage` 漂移），仓库内严禁硬编码个人域名，且界面始终保留裸 IPv6 备用切换以应对 DNS 缓存延迟。
  - 路由器 IPv6 入站放行、DDNS 同步、macOS 防火墙与本机 Surge 联动核查（`ipv6-vif` 确认、个人域名 `DIRECT` 规则与外网连通性测试）收口在独立运维文档与向导脚本中，不耦合进服务端运行时。
