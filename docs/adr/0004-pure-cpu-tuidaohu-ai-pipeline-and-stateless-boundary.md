# 纯 CPU 四层推倒胡强 AI 管线、无状态视角边界与双模式确定性预算

为了在 8GB Apple Silicon Mac 宿主机上实现零显存、单步百毫秒内且具压迫感的推倒胡强 AI，同时保障离线万局自博弈评测的严格可复现与未来玩法扩展能力，我们决定将 `mahjong-ai` 架构锁定为 **「纯同步无状态 `decide(&PlayerView, &DecisionContext, &mut Rng)` 入口 + 公开 `seq` 时序 + `RuleProfile` 解耦」**、**「L1–L4 模块化非神经网络管线（`L4` 择机触发）」** 与 **「离线定额比特级复现 / 实时叠加墙钟硬截断」双模式预算**。

## Considered Options

- **深度信息集树搜索（SO-ISMCTS / MO-ISMCTS）或本地神经网络（ONNX/Candle）**：4 人不完全信息麻将在纯 CPU 百毫秒预算下展开多层树易受 Strategy Fusion 与采样稀疏拖累；神经网络路线依赖外部训练管线、模型权重分发与额外内存/算力开销，偏离家庭单二进制轻量化目标。
- **v1 仅交付 L1–L3 启发式评估，完全放弃 L4 浅层采样**：虽然延迟最低且零方差，但在中后盘多方鸣牌竞争与攻守临界局面缺乏对多方交互的显式前瞻，强 AI 压迫感上限受限。
- **有状态 `AiAgent`（消费 `PlayerEvent` 维护跨回合内部信念）**：在断线重连、局中人类断线 AI 临时接管、快照单步排障与离线并发模拟时必须维护额外的跨步状态同步与克隆逻辑，且相比直接由 `PlayerView` 公开历史重构并无决定性性能优势。
- **纯墙钟超时截断（无定额采样模式）**：在 Rayon 多线程调度下，受宿主机瞬时负载与工作窃取顺序影响，相同随机种子无法产生一致的采样次数与对局结果，破坏离线 A/B 回归基准。
- **直接复用日麻 `xiangting` 默认七对分支或照搬日麻防守权重（现物/筋）**：v1 推倒胡无立直、无日麻式永久振听、允许同牌四张作两对的`豪华七对`，直接复用日麻七对向听或将早巡现物/筋视为绝对安全牌会产生系统性误判。

## Consequences

- **类型级零泄密与跨座时序完备**：`mahjong-ai` 仅依赖 `mahjong-core` 的公开投影 `PlayerView`（牌河 `DiscardEntry` 与鸣牌记录补充公开全局单调序号 `seq`）与静态规则描述符 `RuleProfile`，严禁接触牌墙或他家暗牌；借助 `seq` 可无状态推导每名对手的**同巡过水胡**数学 0 风险窗口及手切/摸切相对鸣牌时序。
- **L1–L4 分层与许可证红线**：全栈坚持 MIT / Apache-2.0 依赖，严禁搬运 AGPL/LGPL 引擎源码。`L1` 以 MIT `xiangting` 处理高频 4 面子 + 1 将牌一般形，配合自研 O(34) 零分配模块精确计算`七对`/`豪华七对`/`十三幺`（测试期以 MIT `shanten-dp` 交叉校验）；`L2` 在向听 `≤ 2` 时运行单人多巡期望 DP（计入全量 v1 番型、自摸 3 倍、杠分与抢杠胡扣减）；`L3` 采用结构化非立直防守特征模型（数学 0 风险过水胡窗 + 组合壁 `Kabe` + 手切/摸切 + 染手/碰碰胡读牌 + 降权早巡现物/筋），以离线自博弈逻辑回归拟合后编译期固化为静态 `const` 表；`L4` 仅在满足触发条件时对 `Copy` 栈上模拟态执行择机 Flat MC + 渐进剪枝。
- **双模式预算与并发确定性**：`L4` 为每个 `(candidate_idx, sample_idx)` 由主种子确定性派生子种子并按索引顺序归约——离线评测模式锁定固定采样上限实现跨线程比特级复现；实时对局模式在批间叠加软预算 `120 ms` / 硬截断 `180 ms` 墙钟保护。
- **算法与演出节奏彻底解耦**：`mahjong-ai` 绝不包含 `sleep` 或出牌节奏逻辑；`mahjong-server` 在专用 Rayon 思考池（`min(逻辑核数 / 2, 4)`）中异步桥接 `decide()`，并统一控制最小落子停顿与响应窗口防泄密节奏。
- **量化防回退门禁**：内置同种子四座镜像自博弈 CLI（含 5 级强度阶梯消融校验），以 4,000 小局对抗纯牌效基线场均净得分 `≥ +1.5` 分/小局、点炮率相对降低 `≥ 25%`、8GB Mac 单步 P95 `≤ 150 ms` 作为 v1 硬性验收标准。
