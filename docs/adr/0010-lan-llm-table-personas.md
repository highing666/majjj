# 局域网小模型毒舌牌友表现层与受控架构演进

> 注：本决策在 Spec #63 初始草案中暂编为 ADR-0009；因 Spec #70 已先行落盘 `docs/adr/0009-landscape-first-table-traditional-tiles-and-fullscreen.md`，本决策正式顺延编号为 **ADR-0010**，并直接承接 ADR-0009 预留的四边贴座名牌与 `personaPockets` 牌桌几何布局。

为了让家庭局域网牌桌上的 AI 摆脱静态「AI 1 / AI 2 / AI 3」沉默出牌的单调感，同时充分利用局域网内常开的 Windows GPU 台式机推理算力，我们决定：**引入由局域网常驻 `llama-server`（OpenAI 兼容 HTTP + `json_schema` 约束解码）驱动的「毒舌牌友」表现层系统（5 位内置`牌友角色` × 6 档`牌友情绪`、2D 漫画厚涂头像与漫画气泡、自家手牌精准事实驱动的心理战吐槽、一键`快捷互动`与跨`对局``牌友记忆`）；显式记录对 `ADR-0001`、`ADR-0003`、`ADR-0007` 的三项受控演进，并严格坚守 `ADR-0004` 纯 CPU 强 AI 独立决策边界**。

## Considered Options

- **仅使用离线静态台词模板库（不接入本地大模型）**：虽然能保持零外部服务依赖，但台词迅速重复且无法结合真实手牌态势、他家互动与历史恩怨动态接茬，无法达成损友互怼与综艺氛围目标。
- **同时维护「局域网 LLM + 离线静态台词降级」双模式**：会引入大量降级分支与真假台词混淆体验，违背「Windows GPU 主机常驻作为家庭局域网必选推理节点」的简化运行定位。
- **让大模型直接参与或微调 AI 的出牌与`鸣牌`决策**：9B 级本地小模型在牌效与防守算牌上容易产生幻觉，会直接破坏纯 CPU L1–L4 引擎已验证的强 AI 基线并污染核心规则测试。
- **允许表现层偷看人类或其他座次暗牌以增加节目效果**：会破坏真人同桌信息不对称的博弈沉浸感，让玩家感到 AI 作弊。

## Consequences

- **受控演进 `ADR-0001`（必选局域网推理服务，不做离线静态模板降级）**：
  - `mahjong-server` 在保持单二进制宿主机运行与零公网依赖的前提下，将局域网 Windows 主机常驻的 OpenAI 兼容 `llama-server` 端点设为必选运行依赖，支持通过命令行参数、环境变量及服务端持久化偏好配置地址。
  - 服务端启动时强校验推理服务连通性与模型可用性，不可达则直接返回清晰中文错误并阻止启动（桌面启动器同步弹窗提示）；`对局`进行中若发生断连或超时，向客户端推送明确告警横幅，不卡死牌局也不伪造静态台词。
  - 推理客户端封装在窄边界异步 `LlmClient` 抽象之后，自动化离线测试与 CI 通过依赖注入本地假 HTTP 服务或确定性 Stub 验证完整契约。
- **受控演进 `ADR-0003` 与 `ADR-0007`（自家手牌事实可读与高光事件短同步）**：
  - 表现层严格遵守信息隐私边界：`小局`进行中仅读取单个 AI 座次自身的 `PlayerView`（含自家完整手牌与全桌公开态势）及由 `mahjong-ai` 纯同步函数预计算的精准手牌事实（最小向听数、精确听口与可见余张、大`番`潜力、进退变化），绝不读取任何他家暗牌；直到`小局`结算公开四家手牌后才开展全桌复盘互喷。
  - 为确保毒舌`牌桌台词`紧贴漫画冲击帧弹出，高光事件（如`鸣牌`、`抢杠胡`、`小局`结算、`快捷互动`）允许服务端执行硬上限约 `1.5s` 的短同步等待再协同送达，超时不阻塞牌局推进。
  - 所有在途推理任务复用座次单调代数守卫，确保人类接管座次、解散`对局`或局面推进后过期回包被静默丢弃。
- **严格坚守 `ADR-0004`（纯 CPU 强 AI 100% 掌控出牌与`鸣牌`决策）**：
  - `mahjong-ai::decide()` 及其 L1–L4 同步无状态流水线与 4,000 小局评测基线保持零行为变化；大模型与`牌友情绪`仅驱动表现层头像与`牌桌台词`，绝不干预出牌、`鸣牌`或胡牌策略。
  - 5 位内置`牌友角色`（急眼快攻哥、阴阳茶艺师、嘴硬死磕王、拱火乐子人、红温老雀神）分别绑定既有的默认 `AiStyle`（快攻 / 均衡 / 防守做大牌），确保角色风格与纯 CPU 牌风表里如一。
- **冻结跨层契约与 `@2x` 漫画厚涂资产预算**：
  - `PersonaId`（5 角色）与 `PersonaMood`（6 档：`Smug`、`Mocking`、`Tilted`、`Nervous`、`Plotting`、`Deadpan`）以 Rust 为单一事实源并通过 `ts-rs` 零漂移导出；`SeatInfo` 扩展 `persona_id` 与 `mood` 并保留 `voice_pack_id` 占位字段。
  - 5 位角色 × 6 档表情差分（共 30 帧）以确定性离线管线打包为单一 `@2x` 图集 `web/src/assets/atlas/personas@2x.{png,json}`，严守 `≤ 2048×2048` 硬件纹理尺寸上限与零 `@3x` 资产纪律，并直接落位在 `ADR-0009` 预留的 `personaPockets` 区域以保证全视口零重叠。
