# 逆时针相对座次展示、大厅环桌选座与无风位 UI 投影

为了同时消除地图方位「上北下南、左西右东」与传统麻将逆时针「东 → 南 → 西 → 北」之间的固有几何冲突、修正试玩中因风位标牌与开局重排导致的上下家误读，并保留核心引擎与战绩持久化的长期扩展性，我们决定：**`mahjong-core`、WebSocket 协议与 JSONL 战绩继续保留规范的逆时针 `Seat::{East, South, West, North}` 内部标识（延续 `ADR-0003`），而全部面向玩家的 UI 层统一隐藏各座风位，改以当前玩家视角的逆时针相对座次（`自家 / 下家 / 对门 / 上家`）展示；大厅取消东西南北命名并改为四边环桌相对选座，同时在 `SeatingRule` 中新增 `KeepLobbySeats`（「按大厅所选座次」）作为新建牌桌默认定座规则（演进 `ADR-0005` 原「默认随机定座」约定）**。

## Considered Options

- **大厅保留东西南北并按地图「上北下南、左西右东」十字排布**：在地图排布下，逆时针顺序会变成 `东 → 北 → 西 → 南`（违背麻将传统 `东 → 南 → 西 → 北`），若强行保持 `东 → 南 → 西 → 北` 又必须把出牌轮转改为顺时针，与现实麻将习惯及既定逆时针核心直接冲突。
- **大厅与牌桌保留传统麻将逆时针东西南北排布**：当自家坐南座时，桌面呈现「上北下南、左东右西」，与日常地理方位直觉相反；且推倒胡规则不计自风/圈风役牌番，玩家在局内展示各座风位既无规则收益又持续制造方位换算负担。
- **在牌桌改为顺时针出牌或重写核心 `Seat` 枚举去除东西南北**：顺时针出牌违背线下麻将习惯；改动核心 `Seat` 枚举会破坏既有 `hands.jsonl` / `matches.jsonl` 持久化兼容，并削弱 `ADR-0003` 为未来带自风番玩法（如日麻、国标）预留的 `Ruleset` 扩展边界。
- **大厅改为四边环桌但仍保持 `SeatingRule::Random` 为默认**：玩家在环桌上刻意点选坐同伴「对门」或「下家」后，开局被静默打乱会产生强烈的“座次错乱”Bug 体感。

## Consequences

- **领域词汇与静态门禁收口**：全站 UI、定座选项文案与文档统一采用 `GLOSSARY.md` 规范词条 `座次`、`自家`、`上家`、`下家`、`对门`（禁用 `对家`），并由全仓术语门禁持续拦截回流。
- **逆时针视角不变量与方向视觉强化**：牌桌始终保持逆时针轮转（`下=自家`、`右=下家`、`上=对门`、`左=上家`，音频声像维持 `上家 -0.35 / 下家 +0.35`）；牌桌四角名牌展示完整两字相对角色与独立 `庄` 标，中央圆印改用四向高亮指针直观呈现当前出牌流向。
- **圈风局数与个人风位解耦**：`东风战`与`自由桌`的局数标题仍保留 `东风圈 第 X 小局`（中央圆印紧凑展示 `东1` 等），仅用于表达牌局进度，不再与单个玩家的座位标签混用。
- **演进 `ADR-0005` 默认定座规则且保持配置兼容**：`SeatingRule` 新增 `KeepLobbySeats` 并设为默认，确保大厅环桌选座所见即所得（首小局`庄家`仍由随机种子公平抽选）；既有 `Random`、`FixedOpposite`、`FixedAdjacent` 全部保留，保障存量 `preferences.json` 平滑反序列化，且选 `Random` 时在大厅显式提示开局洗座。
- **无视角界面统一兜底**：未入座接管页与本地历史战绩无「自家」视角，直接以玩家昵称展示（空昵称兜底 `1~4 号位`），全站不再出现 `东座/南座/西座/北座` 前缀。
