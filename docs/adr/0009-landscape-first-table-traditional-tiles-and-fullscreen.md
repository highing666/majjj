# 横屏优先双端牌桌、传统中国麻将混合图集与沉浸全屏契约

为了修正试玩中暴露出的牌面非中国传统麻将样式、`牌河`错位且归属难辨、轮到`自家`出牌缺乏强提示以及缺乏全屏支持等问题，同时充分释放 Mac 宽屏与 iPhone 横屏的横向空间，我们决定：**延续 `ADR-0001` 与 `ADR-0007` 的 2D 深青暖珀牌桌基调及单张 `@2x` 图集（`≤ 2048×2048`、`maxDpr = 2`）契约，采用 `gemini-api image` 混合资产管线将 34 张`数牌`/`字牌`全面重绘为正宗中国传统麻将视觉（含立/倒双牌体与全站 `TileBadge` 统一）；放弃强行裁为 1:1 正方形，确立「Mac 宽屏 + iPhone 横屏」优先的牌桌几何，将 `ADR-0008` 的四角名牌演进为四边贴座名牌与横屏自适应`牌河`凹槽；并落地四层轮到`自家`出牌强提示与一键沉浸全屏（含 PWA 与 iPhone 视口降级）**。

## Considered Options

- **全桌切换为写实绿呢绒布牌桌风格**：会打破既有深青暖珀视觉体系，并与 `#63` 规划的漫画厚涂`牌友角色`头像及漫画对话气泡产生风格割裂。
- **Mac 宽屏强行锁定 1:1 近似正方形牌桌外框**：在 16:9 / 16:10 宽屏上会白白浪费两侧横向空间并压缩`自家`手牌与`牌河`的可用高度，违背合理利用横屏空间的目标。
- **四家`牌河`维持固定 6 张/行并保留 `ADR-0008` 四角名牌**：在 iPhone 横屏等低高度视口中，上下`牌河`按 6 张/行展开会挤压中央与手牌纵向空间；同时名牌悬置于画布最远四角，与各自`牌河`缺少视觉连线，仍难以快速识别`舍牌`归属。
- **继续以 iPhone 竖屏为主游玩形态或全站禁用竖屏**：竖屏下 14 张手牌与四家`牌河`难以兼顾大尺寸与易点按；而大厅与战绩页禁用竖屏则会削弱单手扫码入座、快速配桌的便捷性。
- **全 34 张牌面纯 AI 端到端生图或纯代码矢量手绘**：纯 AI 逐张生图容易出现筒子/条子点数幻觉、字形走样及后续单张微调困难；纯代码矢量又难以刻画出传统工笔幺鸡与一筒大花轮的手绘神韵。

## Consequences

- **传统中国麻将 34 张牌面、双牌体与混合资产管线**：
  - **万子**：采用粗楷/魏碑刻字质感，上方墨黑中文数字「一～九」+ 下方朱红繁体「萬」（取消细宋体与空心描边）。
  - **条子**：回归传统红绿竹节配色（去除混入的蓝色条子），`2/3/4/6/8` 条以正绿竹节为主，`1/5/7/9` 条红绿经典搭配；一条重绘为传统工笔幺鸡/孔雀立枝；八条采用传统绿色对称 M/W 竹结。
  - **筒子**：取消齿轮辐射白线，改为传统梅花/铜钱花瓣圆饼；一筒为传统大花轮，2–9 筒采用经典绿/红/蓝分组。
  - **字牌与白板**：`東/南/西/北` 粗楷墨黑、`中` 朱红、`發` 正绿；白板采用大陆传统纯白光板（仅保留极淡内凹切面框，取消蓝色虚线框）。
  - **双牌体与全站一致**：`自家`手牌启用带翡翠绿牌背厚度的立牌体，`牌河`与`鸣牌`启用平铺倒牌体；全站缩略牌组件（`TileBadge`，涵盖动作栏、`小局`结算与总结算）同步改用同一套传统牌面图形，不再混用纯文字牌卡。
  - **混合资产管线**：利用本机已配置的 `gemini-api image`（`gemini-nano-banana-2.1` 及 `-i` 风格参考）生成原型风格样张与高美术复杂度核心图案（工笔一条幺鸡、一筒大花轮、梅花筒子与竹节笔触、翡翠牌体质感），再由确定性合成管线将统一牌体与精准粗楷刻字/点数排版打包为单一 `@2x` 图集 `tiles@2x.png`（`≤ 2048×2048`），兼顾传统手绘韵味与零错点、像素级对齐。
- **横屏优先布局、四边贴座名牌与自适应`牌河`（演进 `ADR-0008`）**：
  - **横屏自适应`牌河`凹槽**：中央保留紧凑圆角中盘（展示局数、`牌墙`余张与四向轮转高亮边灯），四家`牌河`严丝合缝贴齐中盘四条边，各自配备暗色凹槽底框与细金边线消除视觉错位。上下两家（`对门`/`自家`）每行排 **8–10 张**（常规两行即可容纳 16–20 张`舍牌`，显著释放纵向空间放大手牌与`牌河`牌面），左右两家（`上家`/`下家`）每列排 **4–6 张**向充裕横向空间延展。
  - **四边贴座名牌**：将 `ADR-0008` 的四角名牌演进为四边贴座名牌，紧贴各自手牌与`牌河`外侧，使「名牌 → 手牌 → `牌河` → 中盘边灯」处于同一视觉轴线，同时为 `#63` AI `牌友角色`头像与漫画气泡提供紧邻座次的落点；逆时针相对座次（`自家`/`下家`/`对门`/`上家`）、独立`庄`标与无风位契约保持不变。
  - **iPhone 横屏策略**：大厅与战绩页维持竖屏友好；进入`对局`（`InMatch`）若检测到手机竖屏窄屏，展示「请横屏旋转手机打牌」全屏引导遮罩（角落保留「临时竖屏查看」跳过入口防止卡死）；横屏对局态自动将顶栏收起为角落极简悬浮图标组，最大化牌桌可视高度。
- **四层轮到`自家`出牌强提示**：
  - ① `自家`手牌托盘外缘亮起呼吸金光（刚摸入牌额外带亮金框并微抬；`碰`后无摸入牌时整排手牌统一呼吸微光）；
  - ② 手牌正上方居中展示紧凑金色提示胶囊「轮到你出牌」（有`鸣牌`/胡牌可选时由动作栏接管，非`自家`回合自动隐藏）；
  - ③ 非`自家`回合手牌轻微压暗降饱和度，轮到`自家`瞬间提亮形成明暗反差；
  - ④ 中盘指向`自家`的边灯同步加粗发光。
  - 遵循 `ADR-0007` 在 `prefers-reduced-motion` 或省电模式下退化为清晰静态高亮；严守 v1 规则红线，绝不显示听牌或荐牌提示。
- **沉浸全屏与默认一屏铺满**：
  - 对局控制区提供一键全屏按钮与快捷键 `F`：在支持原生 Fullscreen API 的 Mac/iPad 浏览器中同步进入系统全屏与沉浸布局（隐藏底栏与页面外边距，顶栏收起为右上角紧凑半透明悬浮图标组：退出全屏/节奏/设置/解散，按 `Esc` 或再次点击恢复）；
  - 在不支持原生 `requestFullscreen()` 的 iPhone Safari 上自动降级为 `100dvh` 视口沉浸模式，并补齐 `manifest.webmanifest` 与 `apple-mobile-web-app-capable`，支持「添加到主屏幕」无地址栏全屏启动；
  - 普通非全屏`对局`页默认按 `100dvh` 一屏铺满无垂直滚动条（将底栏版本号等信息收口至设置或大厅）。
- **渐进式视觉签收流程**：在进入 `/to-spec` → `/to-tickets` 正式开发切片前，先经 `/prototype` 输出传统牌面风格对比（含 `gemini-api image` 生成样张）与 Mac 宽屏 / iPhone 横屏模拟视口牌桌交互原型，肉眼拍板后再冻结实现规格。
