# 流式台词语音与无默认 AI 气泡的语音优先牌桌（修订 `ADR-0011` 与 `ADR-0014`）

在实机体验中，`ADR-0011` 与 `ADR-0014` 采用的「先弹漫画文字气泡 + 异步整句 WAV 合成」架构暴露出明显割裂感：玩家先看到完整`牌桌台词`，随后等待 `2–3.5 s` 才响起`台词语音`，且有声游玩时常驻文字气泡反而分散视线。为了将首音延迟压入亚秒级并打造更贴近真人牌桌的语音优先体验，同时坚守家庭局域网明文 HTTP 零证书直连（`ADR-0005` / `ADR-0012`）、`BENDER` 单卡共驻显存红线与 Mac/iPhone Safari 兼容性，我们决定：**将`台词语音`（`BanterVoice`）端到端升级为 HTTP Chunked Raw PCM16 真流式合成与 Web Audio `AudioBufferSourceNode` 采样级无缝分片播放，同步将牌桌切换为「默认无 AI 文字气泡、仅无声或首包前故障自动文字兜底」模式，并保留人类`快捷互动`短气泡**。

## Considered Options

- **保留明文 HTTP 不可用的 `AudioWorkletNode` 并为家庭局域网全面引入自签名 HTTPS**：`AudioWorklet` 在浏览器中强依赖 HTTPS 安全上下文，在家庭局域网明文 `http://192.168.x.x:8789` 上会被 iPhone Safari 禁用；强上自签名证书会迫使家中每台苹果设备手动安装并信任根证书，彻底破坏扫码即打牌的零摩擦目标；而在 `2–18` 字短句与 `330–500 ms` 分片场景下，`AudioBufferSourceNode` 采样级无缝排程的听感与 `AudioWorklet` 无差异且全端免证书可用。
- **通过现有 WebSocket `/ws` 直接推送二进制音频分片**：虽省去一次同源 HTTP 请求，但音频流会与实时出牌/`鸣牌` JSON 帧争抢同一条连接，违背 `ADR-0002` / `ADR-0011` 信令与媒体分离原则，在`远程联机`弱网下可能拖慢牌局交互。
- **彻底删除所有 AI 文字气泡且不留无声兜底**：实现虽更简，但在深夜静音、iOS Safari 首次未点按解锁音频、关闭`台词语音`或 `BENDER` 维护降级时，玩家将完全不知 AI 说了什么；改为「默认零 AI 气泡 + 无声/首包前失败自动回显」在正常有声时视觉完全一致且保住可用性底线。
- **做 LLM 文本生成到 TTS 的双流式拼接**：`ADR-0015` 下本地 `Qwen3.5-9B` 开启原生思考并受 `json_schema` 约束，必须先拿到 `speak` 与 `mood` 才能确定情感合成指令，且 `4–14` 字短句正文生成仅 `< 200 ms`，双流式收益极微却易破坏情绪与断句完整性。
- **保留气泡并改为「首包出声时再同步弹出」**：虽能消除时间差，但有声游玩时文字气泡仍多余且占用牌桌视野；直接默认隐藏 AI 气泡、靠声音与头像情绪/说话脉冲表达更干净自然。
- **在设置面板保留「始终显示 AI 台词字幕」开关**：当前优先精简设置面板并统一语音优先体验，移除过时的「有声时隐藏台词气泡」开关，避免增加无谓状态分支。

## Consequences

- **端到端真流式 `台词语音` 管线（修订 `ADR-0011` 与 `ADR-0014`）**：
  - **`BENDER` Windows TTS 侧**：`service.py` 改造为基于 `asyncio.Queue` 的真异步边算边吐流，`qwen3-custom-voice`（`generate_custom_voice_streaming`）、`cosyvoice3`（`stream=True`）与 `qwen3-base-clone`（`generate_voice_clone_streaming`）三后端统一优先接入原生流式生成器（旧版底包自动兼容退回切片），默认 `MAJJJ_TTS_STREAM_CHUNK_SIZE=6`（约 `500 ms`，真机可微调至 `4` ≈ `333 ms`）使首块天然自带抗抖动播放余量。
  - **`mahjong-server` 实时扇出与早停取消**：沿用同源 `GET /api/banter-audio/{banter_id}`，收到 `BENDER` HTTP `200` 与首块 PCM16（24 kHz 单声道）后即广播就绪通知，并边收边向所有已连客户端（含持有效会话 Cookie 的`远程联机`）以 HTTP Chunked 渐进吐流，同时写入有界内存缓冲实现单次 GPU 合成多端共享（流完成后入 24 条 / 60s / `< 5 MiB` LRU 缓存）。切`小局`、同座新句抢占、人类接管或回大厅/解散时，服务端主动断开上游连接，`BENDER` 在 chunk 边界早停释放 GPU `Semaphore(1)`。
  - **两段式超时与熔断解耦**：维持 `ADR-0014` 熔断解耦纪律——队列等待加首包到达沿用局中 `5,000 ms` / 结算 `6,500 ms` 截止线，超限/`408`/单槽顶替仅触发单句 `TableBanterAudioFallback` 不计入 15 秒熔断；首包已开播后若遇分片间空闲超时（约 `3,000 ms`）或上游中断，流干净收尾、前端平滑淡出结束且不再补弹文字气泡。
  - **浏览器端播放**：前端通过 `ReadableStream` 逐块读取 Raw PCM16（处理奇数字节拆包对齐），使用 `AudioBufferSourceNode` 按硬件时钟采样级无缝排程（含约 `3 ms` 首尾微淡入淡出）接入现有 `voGain → masterGain → DynamicsCompressorNode` 总线，保留相对声像、30 ms SFX Ducking 与跨座最多 2 句顺延防吵队列，明文 HTTP 与 HTTPS 全端兼容。
- **语音优先无默认 AI 气泡与无声兜底（修订 `ADR-0011` 与 `ADR-0014`）**：
  - 正常有声时局中牌桌彻底隐藏 AI `牌桌台词`文字气泡，LLM 返回即更新头像`牌友情绪`差分、流式首包开播时点亮说话脉冲；`牌桌对话流`仍照常在服务端完整记录文本。
  - 仅在静音、音量归零、Safari `AudioContext` 未处于 `running`、关闭`台词语音`、TTS 不可用/关闭或首包前单句失败时自动弹出文字气泡兜底；人类`快捷互动`走离线`角色语音包`瞬发无延迟，继续常驻短气泡。
  - `小局`结算弹窗与总结算页复盘条同步默认隐藏 AI 文字，仅展示紧凑的「头像 + 情绪标签 + 说话脉冲」卡片，无声兜底时自动展开文字。
  - 移除本机偏好 `hide_banter_bubble_with_voice` 字段与对应设置开关，兼容忽略老设备 `localStorage` 中的残留键。
